# Termule.Demos

The demo collection for the Termule toolkit. See the full toolkit [here](https://github.com/V30P/termule).

## Access
This tool is available on NuGet as `Termule.Demos`. To install use:

```
dotnet tool install Termule.Demos
``` 

## Usage
To run this demo collection, first install the project as shown above. From there, use:

```bash
dotnet termule-demos --help
```

To learn how to use the demo collection, or to run a specific demo by name:

```bash
dotnet termule-demos DEMO
```

For a demo's source code, look for the `.cs` file of the same name in [`Demos/`](Demos/).
