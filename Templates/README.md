# Termule.Templates

The template pack for the Termule toolkit. See the full toolkit repository [here](https://github.com/V30P/termule).

## Access
This extension pack is available on NuGet as `Termule.Templates`. To install use:

```bash
dotnet new install Termule.Templates
```

## Templates
- ### Blank (`termule-blank`)
    An empty project ready for development with Termule. Preconfigured to embed `res/` and publish to a single file.

- ### Hello Terminal (`termule-hello`)
    A sample project rendering text to the terminal via Termule.
